# Кітапхананың ақпараттық жүйесі

Бұл жоба кітапхана жұмысын автоматтандыруға, оқырмандарды тіркеуге және кітап қорын тиімді басқаруға арналған веб-жүйе болып табылады.

## Жобаның мақсаты
Кітапханадағы кітаптар есебін жүргізу, оқырмандарға қажетті әдебиеттерді жылдам табуға көмектесу және кітап алу/қайтару процестерін жеңілдету.

## Негізгі мүмкіндіктері
- Электронды кітап каталогын қарау;
- Кітаптарды атауы, авторы және жанры бойынша іздеу;
- Оқырмандарды жүйеге тіркеу;
- Кітаптарды алу және қайтару мерзімін бақылау.

## Жүйе пайдаланушылары
- **Оқырман:** Кітаптарды іздейді, тапсырыс береді.
- **Кітапханашы:** Кітаптар қорын толықтырады, береді және қайтаруды тіркейді.
- **Әкімші:** Пайдаланушылар мен жүйе баптауларын басқарады.

## Қолданылатын технологиялар
- HTML5 / CSS3 / JavaScript
- Git / GitHub
- Visual Studio Code
