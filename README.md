# Travel Planner

Travel Planner — это информационная система для планирования путешествий.

## О проекте

Система позволяет пользователю планировать поездку, выбирать страну,
интересные места, отель, маршрут и рассчитывать примерный бюджет.

## Основные возможности

- выбор страны;
- добавление интересных мест;
- выбор отеля;
- планирование маршрута;
- расчет бюджета;
- просмотр информации о путешествии.

## Структура проекта

- `index.html` — главная страница проекта;
- `style.css` — стили проекта;
- `script.js` — JavaScript;
- `docs/requirements.md` — требования к системе;
- `docs/use-case.md` — сценарии использования;
- `docs/diagrams/` — диаграммы проекта.

## Цель проекта

Создать удобный планировщик путешествий, который помогает пользователю
организовать поездку в одном месте.
