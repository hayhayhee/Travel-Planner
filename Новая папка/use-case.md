# Use Case

## Пользователь

Пользователь может:

- выбрать страну;
- выбрать место для посещения;
- выбрать отель;
- составить маршрут;
- указать бюджет.

## Основной сценарий

1. Пользователь открывает Travel Planner.
2. Выбирает страну.
3. Просматривает интересные места.
4. Выбирает отель.
5. Создает маршрут.
6. Указывает бюджет.
7. Получает план путешествия.
