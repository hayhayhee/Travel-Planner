# Требования к системе

## 1. Функциональные требования

Система Travel Planner должна позволять пользователю:

1. Выбирать страну для путешествия.
2. Просматривать интересные места.
3. Выбирать отель.
4. Создавать маршрут путешествия.
5. Указывать планируемые расходы.
6. Рассчитывать примерный бюджет поездки.

## 2. Нефункциональные требования

Система должна:

- иметь простой интерфейс;
- быть удобной для пользователя;
- быстро отображать информацию;
- работать в современном браузере.

## 3. Пользователь

Основным пользователем системы является человек,
который планирует путешествие.
